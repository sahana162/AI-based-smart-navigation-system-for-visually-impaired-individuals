# Plan 1.1: Solidify UvcCameraService State Machine & In-Memory Streaming

<objective>
Refactor `UvcCameraService` to be the single authoritative controller for the YJX-C5 smart glasses camera (USB UVC). Eliminate disk-based frame I/O, provide a continuous in-memory throttled sampling loop (2 fps) for background obstacle/pedestrian scanning, and add an on-demand zero-latency frame snapshot extraction method.

Purpose: Eliminate crashes, file locking bugs, and high disk latency caused by redundant controllers and repeated `takePicture()` file I/O.
Output: Production-grade `UvcCameraService` with a robust state machine and stream buffer.
</objective>

  <action>
    Refactor `UvcCameraService` in `lib/core/services/uvc_camera_service.dart`:
    1. Define an explicit enum `UvcConnectionState { disconnected, connecting, connected, streaming, error }`.
    2. Manage a single `UVCCameraController` instance. Provide safe getters for the controller and connection state.
    3. Ensure `initialize()` safely cleans up any previous controller before attempting to open the UVC camera.
    4. Implement retry logic (up to 3 attempts with 1.2s delay) when opening the camera, updating state to `connecting` then `connected`.
    5. Handle native exceptions cleanly and update state to `error` or `disconnected` without crashing the isolate.
    AVOID: Reinstantiating the controller on every scan attempt without disposing of the previous native reference.
  </action>
