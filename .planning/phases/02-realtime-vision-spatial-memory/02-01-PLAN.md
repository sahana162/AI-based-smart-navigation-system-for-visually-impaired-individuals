# Plan 2.1: In-Memory Byte Detection & Clock Spatial Guidance

<objective>
Enable direct in-memory TFLite object detection from `Uint8List` bytes in `ObjectDetectorService`, and enhance `DetectedVisionItem` with fine-grained clock position calculations (10 to 2 o'clock) and combined natural spatial phrasing.

Purpose: Allow continuous hands-free detection on the smart glasses stream without disk wear, while providing visually impaired users with intuitive clock-face bearings.
Output: Zero-disk inference methods and clock-based spatial calculation logic.
</objective>

<task type="auto">
  <name>Implement Clock Position and Combined Spatial Formatting</name>
  <files>lib/core/services/object_detector_service.dart, lib/core/services/vision_service.dart</files>
  <action>
    1. In `DetectedVisionItem`, add field `final String clockPosition;` (e.g., '10 o\'clock', '11 o\'clock', '12 o\'clock', '1 o\'clock', '2 o\'clock').
    2. Compute `clockPosition` based on normalized horizontal center:
       - < 0.25: '10 o\'clock' (far left)
       - 0.25 to 0.42: '11 o\'clock' (slight left)
       - 0.42 to 0.58: '12 o\'clock' (directly ahead)
       - 0.58 to 0.75: '1 o\'clock' (slight right)
       - > 0.75: '2 o\'clock' (far right)
    3. Add helper method `String formatSpatialDescription({bool isKannada = false})` that produces the combined phrasing:
       - Center: "directly ahead, about X meters away"
       - Left: "on your left, 10 o'clock, about X meters away"
       - Right: "on your right, 2 o'clock, about X meters away"
    4. Update `VisionService` spatial helper functions and search methods to expose this combined format.
    AVOID: Breaking existing constructor usages; default `clockPosition` cleanly if omitted.
  </action>
  <verify>flutter analyze lib/core/services/object_detector_service.dart lib/core/services/vision_service.dart</verify>
  <done>DetectedVisionItem provides accurate clock positions and combined natural spatial speech.</done>
