# Plan 2.2: Continuous Smart Glasses Detection & Instant Dual-Check Spatial Queries

<objective>
Subscribe `NavigationScreen` to `UvcCameraService.onFrameStream` for live obstacle/pedestrian detection through wearable smart glasses, connect voice item queries ("Where is my [item]?") to an instant dual-check pipeline (live vision first -> saved memory fallback), and enforce proximity-aware audio fatigue cooldowns.

Purpose: Provide continuous, hands-free sight assistance and instantaneous item localization for blind users.
Output: Integrated wearable detection loop and voice spatial memory system.
</objective>

<task type="auto">
  <name>Connect Smart Glasses onFrameStream to Live Detection Pipeline</name>
  <files>lib/ui/screens/navigation_screen.dart</files>
  <action>
    In `lib/ui/screens/navigation_screen.dart`:
    1. In `_startLiveObstacleMonitoring()`, if `_isUvcActive`, subscribe to `_uvcService.onFrameStream` and start `_uvcService.startStreaming(targetFps: 2)`.
    2. Implement `_handleUvcFrame(Uint8List frameBytes)` that passes raw bytes directly to `_objectDetectorService.detectObjectsFromBytes()` without writing to disk.
    3. Ensure `_handleUvcFrame` runs identical hazard checks, overhead clearance checks, and status updates as phone camera frames.
    4. In `_stopLiveObstacleMonitoring()`, cancel the stream subscription and call `_uvcService.stopStreaming()`.
    5. Ensure seamless switching between phone camera image stream and UVC frame stream during camera toggles.
    AVOID: Running concurrent inferences if the previous frame inference is still active (`_isProcessingFrame`).
  </action>
  <verify>flutter analyze lib/ui/screens/navigation_screen.dart</verify>
  <done>Smart glasses continuously stream frames to on-device object detection at 2 fps.</done>
</task>

<task type="auto">
  <name>Implement Dual-Check Spatial Queries and Proximity-Aware Audio Cooldown</name>
  <files>lib/core/services/voice_session_coordinator.dart, lib/ui/screens/navigation_screen.dart</files>
  <action>
    1. In `NavigationScreen`, implement per-class alert cooldown tracking:
       - Maintain `final Map<String, DateTime> _objectAlertCooldowns = {};`
       - Suppress announcements for the same object class if alerted within the last 12 seconds.
       - BYPASS cooldown if `mostUrgent.position == 'center' && (mostUrgent.estimatedDistanceMeters ?? 99.0) < 1.2` or if `mostUrgent.isOverheadHazard`.
    2. In `VoiceSessionCoordinator` handling `VoiceCommandType.findItem`:
       - Query active camera frame via delegate or `uvcCameraService.getLatestFrame()`.
       - Run on-device detection for the requested item.
       - If detected in current camera frame: announce immediately using combined clock format (*"I see your keys right now, on your left, 10 o'clock, about 1 meter away."*).
       - If not detected in current frame, check `storageService.findRememberedItem(item)`.
       - If found in memory: announce the saved location and timestamp (*"Not visible in your current view. You last remembered placing it on the dining table."*).
       - If neither: announce honest not-found guidance.
    AVOID: Requiring conversational prompts asking the user if they want to look; perform the visual inspection automatically.
  </action>
  <verify>flutter analyze lib/core/services/voice_session_coordinator.dart lib/ui/screens/navigation_screen.dart</verify>
  <done>Instant dual-check spatial queries and 12-second fatigue cooldown are fully operational.</done>
</task>
