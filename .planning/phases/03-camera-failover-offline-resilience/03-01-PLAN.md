# Plan 3.1: Cloud Degradation, Fast-Fail Offline Routing & Unified RECALL_ITEM

<objective>
Implement instantaneous (< 50ms) offline degradation for `GeminiLiveService` when network connectivity is lost, wire seamless offline fallback without erroneous API key announcements, unify `[ACTION:RECALL_ITEM:<item>]` with the live-frame dual-check, and ensure `PedestrianNavigationService` provides spoken accessibility guidance with direct compass bearing mode when offline.

Purpose: Keep conversational assistance and navigation completely operational when the user enters an elevator, basement, or area without mobile data.
Output: Fast-failing cloud service, graceful local intent fallback, unified spatial recall, and offline compass routing.
</objective>

  <files>lib/core/services/gemini_live_service.dart</files>
  <action>
    In `lib/core/services/gemini_live_service.dart`:
    1. In `converse()`, inspect exceptions caught during candidate model HTTP calls.
    2. Detect network disconnection (`SocketException`, `http.ClientException`, `TimeoutException`, `HandshakeException`, or offline status).

       - Instantly return `'__FALLBACK_LOCAL__'` in < 50ms.

    AVOID: Retrying cloud models when network connection is completely broken.
  </action>

  <done>GeminiLiveService instantly returns __FALLBACK_LOCAL__ upon network disconnect without delaying execution.</done>

<task type="auto">
  <name>Harden Offline Voice Fallback & Unified RECALL_ITEM in VoiceSessionCoordinator</name>
  <files>lib/core/services/voice_session_coordinator.dart</files>
  <action>
    In `lib/core/services/voice_session_coordinator.dart`:
    1. In `askGeminiWithVision()`, if `reply == '__FALLBACK_LOCAL__'` or network failure occurs:
       - Do NOT speak "Gemini Live connection failed, check API key".
       - If offline, speak an informative transition: (Kannada: "ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿದೆ, ಸ್ಥಳೀಯ ಕ್ಯಾಮೆರಾ ಪರಿಶೀಲಿಸಲಾಗುತ್ತಿದೆ...", English: "Operating offline. Checking with local vision...") and fall back to local offline action or `findItem`.
    2. In `processRecognizedText()`, when `[ACTION:RECALL_ITEM:<item>]` is received:
       - Perform the identical instant dual-check as offline `findItem`:
         a. If `_navDelegate` has an active camera, fetch the latest frame bytes and call `visionService.detectObjectsFromBytes()`.
         b. If matching item is detected in the current view, speak its real-time clock position and distance immediately.
         c. If not visible in current view, query `storageService.findRememberedItem(item)` and speak the stored placement location.
    3. Ensure conversational fallback when `converse()` returns `'__FALLBACK_LOCAL__'` drops straight into `VoiceCommandParser.parse(trimmed, assistantName)` with zero user-facing delay.
    AVOID: Announcing API key errors when the actual root cause is an offline network.
  </action>
  <verify>flutter analyze lib/core/services/voice_session_coordinator.dart</verify>
  <done>VoiceSessionCoordinator falls back to local parser and executes instant dual-check on RECALL_ITEM without API error spam.</done>
</task>
